⚙️ Настройки API и Парсеров

Здесь вы можете указать ключи для работы парсеров. Без них сбор мемов из VK и Telegram невозможен.

ВКонтакте (VK API)
👉 Где взять ключ?
1. Зайдите на vk.com/dev
2. Создайте приложение (Тип: "Сайт" или "Standalone").
3. Скопируйте Сервисный ключ (Service Token) и вставьте ниже.
Telegram (MTProto)
👉 Где взять API ID и Hash?
1. Зайдите на my.telegram.org
2. Войдите по номеру телефона -> "API development tools".
3. Создайте приложение и скопируйте App api_id (число) и App api_hash (строка).
Общие настройки
Собирать посты, опубликованные не ранее чем N часов назад.
